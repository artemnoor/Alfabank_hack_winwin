# AlfaBank Hackathon Framework

The repository is a modular-monolith foundation for a hackathon system. The
approved architecture, operation catalog, and contracts are in
`docs/specs/framework-v1/`. The current implementation milestone is T01 after
the completed T00 toolchain/bootstrap work.

The approved stack is Python 3.12, Pydantic v2, FastAPI, PostgreSQL 16,
SQLAlchemy 2, Alembic, React, TypeScript, and Vite. Use only the technologies
required by the current task. Python and Node versions, uv/npm versions, and
PostgreSQL image digest are pinned by T00 manifests and lockfiles.

The user-facing project documentation is Russian. Code identifiers and
technical terms remain in their ecosystem-standard form.
