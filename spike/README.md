# Experimental spikes

This directory contains isolated experiments for the AlfaBank Hackathon framework. Its contents are **test results and prototype code**, not production behavior. A spike may be proposed for integration into the main implementation only after its tests, security review, taxonomy decisions, and contract fit have been evaluated and accepted. Nothing here is merged into the application runtime by this directory alone.

## T08 — Jev news classification

See [T08](T08/README.md) for the Jev-only classification experiment, candidate taxonomy, synthetic hand-labeled corpus, harness, and results. The proposed labels are a draft for review; they do not change the normative OpenAPI or the production Understanding implementation.
